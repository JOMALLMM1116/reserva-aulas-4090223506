Acerca del proyecto

¿Qué es este sistema?

El Sistema de Reserva de Aulas es una propuesta diseñada para resolver una necesidad real dentro de la universidad: que los estudiantes puedan reservar aulas disponibles cuando las necesiten para sus proyectos, reuniones de grupo o tutorías académicas, sin tener que recurrir a procesos manuales.

Como parte de esta práctica, se modeló el sistema utilizando notación UML estándar, abarcando las fases de análisis (casos de uso y actividades) y diseño (modelo entidad-relación), siguiendo las buenas prácticas de la ingeniería de software.

Funcionalidades

¿Qué se puede hacer en el sistema?

El sistema está diseñado para dos tipos de usuarios con responsabilidades bien definidas:

Alumno

Para los estudiantes

  • Registrarse en el sistema con su correo institucional
  • Iniciar sesión de forma segura
  • Consultar la disponibilidad de aulas en tiempo real
  • Reservar un aula para un horario específico
  • Consultar el estado de sus reservas activas
  • Cancelar una reserva si ya no la necesita
Administrador

Para los administradores

  • Iniciar sesión en el panel administrativo
  • Consultar todas las reservas activas del sistema
  • Aprobar las solicitudes de reserva pendientes
  • Rechazar reservas que no cumplan los criterios
  • Llevar control del uso de las aulas

Diagrama de Casos de Uso

2

Diagrama de Actividades

Representa el flujo completo del proceso de reserva utilizando carriles (swimlanes) para diferenciar las responsabilidades del Alumno, el Sistema y el Administrador. Incluye puntos de decisión, manejo de errores con reintento y el flujo opcional de cancelación de reserva.

3

Diagrama Entidad-Relación

Modela las cuatro entidades principales del sistema (Alumno, Aula, Reserva y Administrador) usando notación Crow's Foot. Define los atributos, claves primarias, claves foráneas y las cardinalidades que relacionan cada entidad para representar correctamente la estructura de la base de datos.
